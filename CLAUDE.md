# Claude project guidance

This is a public, recruiter-facing repository.

- Keep it public-facing only: résumé, cover letter, portfolio links and short evidence notes. Never add internal playbooks, planning notes or session logs.
- Never publish a home street address or other private contact details beyond what the owner approves.
- Label simulated and self-directed projects accurately. Never invent experience, clients, results or credentials.
- Inspect Git status first; commit only task-related changes; never force-push.
